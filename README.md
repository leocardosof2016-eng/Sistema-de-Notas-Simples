# Sistema-de-Notas-Simples

A ideia desde código surgiu quando iniciei o projeto da aplicação de criação e visualização de flashcards.
Para criar aquele site, tive que me debruçar no estudo da manipulação de DOM e hierarquia.
Sendo assim, para melhor compreensão dos métodos 'document.createElement()' e o sistema de hierarquia e adoção de elementos num documento HTML, decidi criar esse sistema simples de criação e exclusão de notas adesivas.

Requisitos funcionais: 
1. Permitir a criação das notas via interação com o usuário
2. Permitir a exclusão das notas via interação com o usuário
3. Sistema de contagem de notas adaptativa. Ex: um contador universal da quantidade de cartas ou um sistema que muda o valor das notas de acordo com a quantidade total naquele momento.
